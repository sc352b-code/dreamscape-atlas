# Dreamscape World Engine v1 — Privacy boundaries

## Private source layer
Never publish to the public repository/runtime:
- raw dream PDFs, documents or exports
- full extracted dream text
- identifiable real-person references
- raw analytical workbooks
- source evidence files containing private narrative material

## Derived private layer
Keep private unless explicitly reviewed and approved:
- structured corpus models
- evidence-backed place/theme/symbol extraction
- territory formation reasoning
- place-level evidence and excerpts
- identifying relationship or chronology data

## Public-safe runtime layer
May be published after review:
- approved planet/flat-map artwork
- non-sensitive territory names and descriptions
- public-safe world/runtime manifests
- approved aggregate counts
- asset hashes and validation metadata
- renderer configuration

## Rules
1. Public runtime manifests must not contain raw dream excerpts.
2. Unknown counts remain `null`; never fabricate them.
3. A derived artifact becomes public only after it is intentionally classified as public-safe.
4. The engine must be capable of regenerating public runtime assets from private inputs without exposing those inputs.
5. User approval applies to the derived output, not to publication of the underlying corpus.
